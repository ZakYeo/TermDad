# Term Dad video demonstrations

Both videos were recorded from real Codex sessions controlling WezTerm through
Term Dad. Pauses are shortened and captions describe the workflow.

| Video                                                               | Demonstration                                                                                                              | Duration | Size   |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | -------- | ------ |
| [Video 1: A team of workers](term-dad-team-demo.mp4)                | Activate Term Dad, launch Claude, Codex, and shell workers, visit their tabs, and verify the results.                      | 2:25     | 6.1 MB |
| [Video 2: From an empty terminal](term-dad-empty-terminal-demo.mp4) | Launch Codex from a fresh shell, run a local service and request checks in split panes, visit Claude, and verify shutdown. | 2:36     | 4.6 MB |

The recordings use an isolated checkout example. Both MP4s use H.264 video and
are below 10 MB. Video 1 also has a [GitHub-hosted playback copy](https://github.com/user-attachments/assets/73713c38-565d-4fb6-93b0-2742b80ccef4)
embedded in the main README.
